# Ubucon 2026 Website

This is the repository for the Ubucon 2026 website. It is built using React, TypeScript, Vite, and the Vanilla Framework.

## Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [pnpm](https://pnpm.io/) (Package manager)
 
## Setting up the Repository

1. Clone the repository to your local machine
   ```bash
   git clone https://github.com/ubuntu-in/website -b ubucon-india-2026
   ```

2. Install the project dependencies using pnpm:
   ```bash
   pnpm install
   ```

3. Start the development server:
   ```bash
   pnpm dev
   ```
   The website will typically be available at [http://localhost:5173/](http://localhost:5173/).

## Building for Production

To create a production-ready build, run:
```bash
pnpm build
```

## Linting

To check the code for linting errors, run:
```bash
pnpm lint
```
