# UbuCon India 2026 Website

This is the repository for the UbuCon India 2026 website. It is built using React, TypeScript, Vite, and the Vanilla Framework.

## Prerequisites

Before you begin, make sure you have [**bun**](https://bun.com/) installed. Or you can use the node package manager of your choice, like npm, pnpm etc. You can easily install node with

```bash
sudo snap install node --classic
```


## Setting up the Repository

1. Clone the repository to your local machine
   ```bash
   git clone https://github.com/ubuntu-in/website -b ubucon-india-2026
   ```

2. Install the project dependencies using pnpm:
   ```bash
   bun i
   ```
   or

   ```bash
   pnpm install
   ```

3. Start the development server:
   ```bash
   bun run dev
   ```
   or
   
   ```bash
   pnpm dev
   ```
   The website will typically be available at [http://localhost:5173/](http://localhost:5173/).

## Linting

To check the code for linting errors, run:
```bash
bun run lint
```
or

```bash
pnpm lint
```
